# 🍅 番茄钟 Pro v2.0（Chrome 扩展）

简洁的番茄钟 Chrome 扩展，不上架商店，直接加载使用。

## 功能

1. **自定义时长** — 默认 25 分钟，可自由调整（1-120 分钟）
2. **暂停 / 继续 / 重置** — 完整控制计时流程
3. **后台计时** — 浏览器关闭也能继续计时（Chrome alarms API）
4. **系统通知** — 计时结束弹出桌面通知
5. **页面内弹窗** — 计时结束时在当前网页显示覆盖层提醒
6. **统计页面** — 独立页面展示：
   - 汇总卡片（总番茄数、总小时、今日番茄、连续天数）
   - GitHub 风格年度贡献热力图
   - 月度柱状图（个数 + 时长）
   - 周分布统计
   - 今日详情时间线
7. **数据持久化** — 所有数据保存在本地，支持导出/导入备份

## 安装

1. 打开 Chrome → `chrome://extensions/`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择 `pomodoro-extension` 文件夹

## 数据备份

统计页面顶部有「导出数据」和「导入数据」按钮：
- **导出** — 下载 JSON 备份文件
- **导入** — 从 JSON 文件恢复数据（会覆盖现有数据）

## 文件结构

```

├── manifest.json      # 扩展配置
├── background.js      # 后台计时逻辑 + 统计存储 + 数据迁移
├── popup.html         # 弹窗界面
├── popup.js           # 弹窗交互逻辑
├── content.js         # 页面内弹窗提醒
├── stats.html         # 统计页面
├── stats.js           # 统计页面逻辑 + 导出导入
├── icons/             # 图标
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md
```

## 技术要点

- **Manifest V3** — 最新扩展规范
- **chrome.alarms** — 后台持久计时
- **chrome.storage.local** — 本地存储统计数据
- **chrome.notifications** — 系统级通知
- **content script** — 页面内弹窗注入
- **数据迁移** — 自动将旧格式数据转换为新格式
